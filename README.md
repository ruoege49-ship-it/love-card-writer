# Love 写卡机

作者：if love

SillyTavern（酒馆）扩展，在酒馆里写角色卡。先和 AI 聊主题，再选卡种，按步骤写人设、世界观、NPC、路线、开场白，质检后导入酒馆。里面还带预设工坊和状态栏工坊。

## 安装

酒馆里打开「扩展」→「安装扩展」，填：

```
https://github.com/ruoege49-ship-it/love-card-writer
```

装好后在魔术棒菜单里能看到「Love 写卡机」「预设工坊」「状态栏工坊」。

## 功能

- **写卡**：先聊主题，再选卡种（单人、多人、世界、手枪、同人、系统游戏、副本、模拟器），每种卡有自己的步骤和预设。质检会查重复内容和全篇八股。
- **状态栏和主页**：有三种来源。可以用现成套装；可以选「聊天做一个」，去状态栏工坊直接读草稿，聊着做状态栏和开场白主页，做好接回这张卡；也可以从状态栏工坊「我的」里选。导入时一起装进卡里，状态栏规则放在世界书 D1。
- **预设工坊**：直接改一份预设。
- **状态栏工坊**：按卡做状态栏和开场白主页，做好写进角色卡，也能存进「我的」以后换卡用。

## 说明

- 草稿和设置存在酒馆扩展设置的 `loveCardWriter` 里，和以前的写卡工坊分开，不会读旧版留下的草稿和设置。
- 默认提示词和人设模板来自灰鸠老师。

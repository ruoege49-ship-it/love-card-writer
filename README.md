# Love 写卡机

作者：if love

SillyTavern（酒馆）扩展，在酒馆里写角色卡。先和 AI 聊主题、定卡种，再按步骤写人设、世界观、NPC、路线、开场白，质检后导入酒馆。里面还带预设机和状态栏机。

## 安装

酒馆里打开「扩展」→「安装扩展」，填：

```
https://github.com/ruoege49-ship-it/love-card-writer
```

装好后在魔术棒菜单里能看到「Love 写卡机」「Love 预设机」「Love 状态栏机」。

## 功能

- **写卡**：先聊主题，聊的时候顺便定卡种（单人、多人、世界、手枪、同人、系统游戏、副本、模拟器），每种卡有自己的步骤和预设。质检会查重复内容和全篇八股。
- **开场白**：可以按按钮写，也可以在开场白页和 AI 聊着写，聊出来的一键放进页面。
- **状态栏和主页**：可以用现成套装，可以去状态栏机聊着做，也可以从「我的」里选。导入时一起装进卡里，状态栏规则放在世界书 D1。
- **预设机**：直接改一份预设，条目可以自己加，也可以让 AI 写。
- **状态栏机**：按卡做状态栏和开场白主页，写进角色卡，也能存进「我的」以后换卡用。

## 说明

- 草稿和设置存在酒馆扩展设置的 `loveCardWriter` 里，不会发到别处。
- 默认提示词都可以在「提示词」页里改，改了自动保存。
